# Tyrano Standing Previewer

[アプリを開く](https://tetoriapot.github.io/tyrano-standing-previewer/)

ティラノスクリプト向けの立ち絵確認・タグ生成ツールです。PNG・JPEG・WebPを読み込み、位置や表情を確認してタグを書き出せます。

左の「キャラクター一覧」でキャラクターを管理し、「表情差分」でキャラクター別に画像を選択・編集します。未分類画像は表情差分のキャラクター欄から選び、所属を設定できます。

画像一覧から個別削除できます。「画像を一括削除」では立ち絵・未分類・背景を選び、対象を確認してまとめて削除します。Undoで戻せます。履歴の再現に必要な画像は保持します。

「キャラクター一覧」の「キャラクターを一括削除」では、複数人を選んで所属する表情画像とまとめて削除できます。画像削除後に残ったキャラクターは「表情0枚」で絞り込み、全選択できます。確定前に対象とシーンへの影響を確認し、1回のUndoで戻せます。過去のシーンを履歴から復元すると、必要なキャラクターと画像も一覧に戻ります。

画像と編集内容はブラウザ内で処理・自動保存します。画像をサーバーへ送信する機能はありません。ブラウザやアクセス先を変える場合は「プロジェクト保存」から画像同梱ZIPを書き出し、移行先で読み込んでください。サイトデータを削除するとブラウザ内の保存内容も消えます。

右上に更新情報、ライト／ダーク切替、ヘルプがあります。

上部の「初期状態に戻す」では、画像・キャラクター・背景・履歴・プロジェクト設定を確認してまとめてリセットできます。配色・文字サイズ・パネル設定と元画像ファイルは保持します。初期状態は自動保存され、直後は1回のUndoで戻せます。再読み込み・終了後は戻せないため、残す場合は先に確認画面から画像同梱ZIPを保存してください。

ボタンや設定欄にマウスを重ねると操作説明が出ます。Tabキーで選択した項目にも表示し、使えない主要ボタンには操作に必要な条件を示します。マウスを外すか、クリック・入力・Escで閉じます。

このリポジトリには公開用にビルドした静的ファイルを置いています。利用者の画像・プロジェクトデータや、ティラノスクリプト本体は含みません。
